Sunucu yaması (Penpot MCP 2.18 fork)

  • Ayarlanabilir gövde sınırı (PENPOT_MCP_MAX_BODY)
  • Asenkron işler: submit_code, job_status, cancel_job
  • Kullanıcı başına FIFO kuyruk, meşgulü “canlı” sayma, yetim görev koruması
  • Yinelenen sekmede takeover-stale politikası
  • Oturum TTL temizliği, server_stats, batch_execute
  • 36/36 birim + 15/15 duman testi
